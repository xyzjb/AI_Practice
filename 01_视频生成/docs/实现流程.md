## 工具链

| 环节 | 工具 / 产物 |
|---|---|
| 选题检索 | 全网搜索（新华网、央视网、澎湃、财联社、界面、凤凰科技、CNBC、TechRepublic 等），窗口为近 7 天 |
| 内容生成 | 5 选题对比表 → 选爆点 → 60–90 秒科普口播稿（约 350 字） |
| 配音 | `edge-tts`（Windows 上清华镜像源无该包，改用默认 PyPI 源） |
| 配图 | AI 生成竖版抽象背景图 7 张 |
| 场景编排 | 每屏一个 `NN.scene.json`，含 `layout` / `themeId` / `orientation` / `slots` |
| 渲染清单 | `scenes.json`：图音以 `data:...;base64` 内嵌进 `bgUrl` / `audioUrl`，并写入 `durationInFrames` |
| 渲染 | VibeKnow + Remotion，流程为 `TTS → build-manifest → render` |
| 成片 | `成片.mp4`：79.7 s，1080×1920，7 屏 |

## 步骤

1. **搜热点**：限定近 7 天，多源交叉，得到 5 个候选选题。
2. **打分选型**：按话题热度、大众相关度、反差钩子、科普价值、争议互动潜力、内容安全风险六维对比，选出「美联航封杀 AI 助手订机票」。
3. **写口播稿**：3 秒反差钩子 → 事件 → 概念解释（智能体 vs 聊天机器人）→ 三方风险 → 反差数据 → CEO 原话 → 互动提问；附事实核查与来源链接。
4. **配音**：`edge-tts` 逐屏生成 mp3。
5. **生图**：为 7 屏各生成一张竖版背景图。
6. **编排**：写 7 个 `NN.scene.json`；由工具链汇总成 `scenes.json`（含 base64 图音与每屏帧数）。
7. **渲染**：Remotion 渲染竖版视频并混流配音。
8. **校验**：用 `ffprobe` 核对时长与分辨率，确认 79.7 s / 1080×1920。

## 提示词要点（整理，非原文）

- **生图方向**：抽象、电影感、竖版构图、深色严肃主题（`serious-dark`），不含具体人物与文字，避免与字幕冲突。
- **标题槽位**：`slots.title` 用 `|` 做视觉分段（如 `AI替你付钱|被拒`），副标题补充事实出处。
- **口播稿约束**：60–90 秒、约 350 字、口语化、开头 3 秒反差钩子、结尾留互动问题，事实需多源核验。

## Windows 环境踩坑（来自工作记录）

1. **系统缺 `ffprobe`**：`build-manifest` 读不到旁白 mp3 时长，每屏回退默认帧数，成片只有 25 秒、旁白被截断。解决：把 Remotion compositor 自带的 ffprobe 加入 PATH。
2. **不要把整个 compositor 目录加进 PATH**：其中的 `ffmpeg.exe` 会干扰 Remotion 音频混流。正确做法是单独 shim 目录，只放 `ffprobe.exe` + 所需 `*.dll`（本地已建在 `_bin/`，按约定未入库，可复用）。
3. **渲染收尾校验失败**：会留下 `.part.mp4` 不改名；手动用 ffprobe 校验通过后再重命名即可。
4. **标题字数校验更严格**：`render` 把 `|` 分段符也计入标题字数，而 `check-slots` 不计；竖版标题需预留 1 个字符余量。
5. **`edge-tts` 安装**：清华镜像源无该包，需改用默认 PyPI 源。
6. **下次执行**：复用 `_bin/` shim（PATH 前置）+ 已装好的环境，可直接跑 TTS → build-manifest → render 全流程。

## 关于 `scenes.json`

该文件约 14.8 MB，把 7 张 PNG 与 7 段音频以 base64 直接内嵌，属于渲染输入清单而非源码。内嵌 PNG 带 AIGC 内容标识元数据（生成方备案编号、ProduceID、SM2/phash 完整性签名），已核查不含账号、邮箱、密钥或本机路径。若后续对仓库体积敏感，可改为按文件路径引用素材，并改用 Git LFS 或 Release 附件存放大文件。
