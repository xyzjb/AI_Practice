## 实现使用的提示词

本次实现由 WorkBuddy 定时任务「**AI科技视频生成**」驱动。以下是该任务的**提示词原文**（由用户提供、并与任务配置逐字核对；非改写、非摘要）：

```text
每天搜索全网最新的AI科技热点新闻，筛选出5个大众关注度高、适合短视频传播的热门选题，每个选题附上热点来源链接。对比这5个选题的话题热度与传播潜力，选出最具爆点潜力的1个，撰写一篇60-90秒的科普口播稿，要求：开头3秒内有强吸引力（悬念或反差），内容通俗易懂、科学准确，避免专业术语堆砌，结尾有互动引导。
最后调用"VibeKnow视频专家"，将文稿自动生成一条适合抖音、小红书、视频号发布的竖版科普视频，并返回生成结果。
```

| 属性 | 值 |
|---|---|
| 来源 | WorkBuddy 自动化任务「AI科技视频生成」的任务提示词 |
| 调度 | 每天 09:44（`FREQ=DAILY;BYHOUR=9;BYMINUTE=44`） |
| 有效期 | 2026-11-12 ~ 2026-11-30 |
| 状态 | ACTIVE |
| 关联产物 | 2026-11-13 期的选题日报、口播稿与成片 |

提示词各环节与本仓库产物的对应关系：

| 提示词要求 | 落地产物 |
|---|---|
| 搜 5 个热点选题、附来源链接 | `选题日报与口播稿-20261113.md` 第一节表格 |
| 对比话题热度与传播潜力、选 1 个爆点 | 同文件第二节六维对比表与结论 |
| 60–90 秒科普口播稿（3 秒钩子、通俗准确、结尾互动） | 同文件第三节成稿（约 350 字） |
| 调用「VibeKnow 视频专家」生成竖版视频 | `scenes.json` + 7 个 `NN.scene.json` + `成片.mp4` |

> 说明：`docs/实现流程.md` 的「提示词要点」是从产物与工作记录反推的**生图 / 排版约束**，属于流程补充；任务级原始提示词以本节为准。生图用的具体英文提示词未完整留存，仅能从本地 `_img/` 文件名看到开头片段（`abstract_cinematic_vertical_co...`、`abstract_vertical_composition__...`）。
