# AI_Practice

在 WorkBuddy 上做的一些 AI 实践记录。当前归档第一项：**每日 AI 科技热点自动化短视频**（2026-11-13 期）。

> 本仓库用于归档「尝试过程 + 最终成果」，**不是可直接运行的工程项目**。
> 生成脚本与原始提示词未随本地产物保留，`docs/` 下是根据工作记录整理的**复现说明**，并非原始源码。

| 项目 | 内容 |
|---|---|
| 期次 | 2026-11-13 |

## 全链路

```text
全网搜热点 → 5 选题对比打分 → 选定爆点 → 60–90s 口播稿 → edge-tts 配音
→ AI 生成 7 张竖版背景图 → 场景配置 / 渲染清单 → VibeKnow + Remotion 渲染 → 成片校验
```

详见 [docs/实现流程.md](docs/实现流程.md)，踩坑与环境记录见 [docs/工作记录-2026-11-13.md](docs/工作记录-2026-11-13.md)。
